# ShoppyGlobe

ShoppyGlobe is a React + Vite e-commerce project built for the React project assignment.

Repository: https://github.com/nithil17/shoppyglobe.git

## Features

- Product list fetched from `https://dummyjson.com/products`
- Product detail pages with dynamic route parameters
- Redux Toolkit cart state with add, remove, increase, decrease, clear, and selectors
- Redux-powered product search
- Cart page with item quantity controls
- Checkout form with order summary, order confirmation, cart clearing, and redirect
- 404 page for unknown routes
- React Router `createBrowserRouter`
- Lazy-loaded pages/components with `React.lazy` and `Suspense`
- Responsive CSS styling and lazy-loaded product images

## Run Locally

```bash
npm install
npm run dev
```
